# 개발 일정표

## 1. 문서 목적

본 문서는 MVP 기능 구현을 위한 권장 개발 일정표다. 절대 날짜가 아니라 작업
순서와 의존관계 기준의 상대 일정으로 작성한다.

## 2. 일정 수립 기준

- 인증과 프로젝트 컨텍스트를 먼저 완료한다.
- 도메인 객체 CRUD를 안정화한 뒤 관계 기능을 구현한다.
- 검색은 도메인 데이터와 권한 정책이 정리된 뒤 구현한다.
- 각 단계는 구현, 테스트, 보완까지 포함해 마감한다.

## 3. 권장 일정

### 1주차. 인증 및 프로젝트 컨텍스트

목표:

- 로그인 및 진입
- 프로젝트 생성 및 프로젝트 목록

세부 작업:

- Supabase Auth 기반 GitHub, Google 로그인 연동
- 최초 로그인 사용자 프로필 생성
- 로그인 후 프로젝트 목록 진입 처리
- 프로젝트 생성 2단계 플로우 구현
- 생성자 자동 멤버 등록
- 프로젝트 목록 조회 및 접근 제어 처리

산출물:

- 로그인 화면
- 프로젝트 목록 화면
- 프로젝트 생성 플로우
- 프로젝트 접근 제어 기본 구조

완료 기준:

- 로그인 후 프로젝트 목록 진입 가능
- 프로젝트 생성 후 목록과 상세 진입 가능
- 멤버가 아닌 프로젝트는 접근 차단 가능

### 2주차. 기본 도메인 CRUD

목표:

- 에픽 생성 및 조회
- 태스크 생성 및 조회
- 문서 생성, 수정, 조회

세부 작업:

- 에픽 생성 폼, 목록, 상세 구현
- 태스크 생성 폼, 목록, 상세 구현
- 태스크 상태값 제한 처리
- 태스크 생성 시 에픽 선택 처리
- 문서 목록, 상세, 편집 화면 구현
- 문서 편집 스플릿 뷰 및 프리뷰 처리
- 명시적 저장 플로우 구현

산출물:

- 에픽 화면 세트
- 태스크 화면 세트
- 문서 화면 세트

완료 기준:

- 프로젝트 안에서 에픽, 태스크, 문서 생성 가능
- 태스크와 문서 상세 조회 가능
- 문서 편집 및 저장 가능

### 3주차. 관계 기능

목표:

- 태스크-문서 연결
- 문서-문서 연결

세부 작업:

- 태스크 상세에서 관련 문서 연결/해제 UI 구현
- 문서 상세에서 관련 문서 연결/해제 UI 구현
- 연결 대상 프로젝트 범위 제한 처리
- 중복 연결 방지 처리
- 해제 후 목록 상태 반영

산출물:

- 태스크 상세 관계 섹션
- 문서 상세 관계 섹션
- 연결용 공통 검색 또는 선택 UI

완료 기준:

- 태스크에서 문서 연결/해제 가능
- 문서에서 관련 문서 연결/해제 가능
- 다른 프로젝트 문서는 연결 대상에 노출되지 않음

### 4주차. 검색 및 통합 검증

목표:

- 프로젝트 내부 검색
- 전 기능 통합 검증

세부 작업:

- 프로젝트 범위 에픽, 태스크, 문서 검색 구현
- 연결 대상 검색에 동일 범위 정책 적용
- 빈 상태 및 권한 오류 처리
- 주요 사용자 시나리오 E2E 수준 검증
- 누락된 입력 검증, 접근 제어, UI 보완

산출물:

- 프로젝트 내부 검색 UI
- 통합 테스트 시나리오
- 릴리즈 전 보완 목록

완료 기준:

- 현재 프로젝트 데이터만 검색 가능
- 연결 대상 검색에도 동일 정책 적용
- MVP 핵심 사용자 흐름 전부 검증 완료

## 4. 병렬 처리 가능 작업

- 인증 UI와 사용자 프로필 저장 로직
- 프로젝트 생성 UI와 프로젝트 목록 조회 UI
- 에픽 CRUD와 문서 편집 UI
- 태스크-문서 연결 UI와 문서-문서 연결 UI

단, 아래 항목은 선행 작업이 필요하다:

- 프로젝트 생성 전에는 에픽, 태스크, 문서 기능을 완료 처리할 수 없다.
- 태스크 및 문서 상세 전에는 연결 기능을 완료 처리할 수 없다.
- 검색 대상 데이터 전에는 검색 기능을 완료 처리할 수 없다.

## 5. 일정 리스크

- 인증 연동이 지연되면 전체 일정이 밀린다.
- 프로젝트 멤버십 모델이 불안정하면 검색과 연결 범위 정책이 함께 흔들린다.
- 문서 편집기 구현이 늦어지면 관계 기능과 검색 검증도 늦어진다.

## 6. 최종 마일스톤

1. 로그인 후 프로젝트 목록에 진입할 수 있다.
2. 프로젝트를 생성하고 접근할 수 있다.
3. 프로젝트 안에서 에픽, 태스크, 문서를 생성할 수 있다.
4. 태스크와 문서, 문서와 문서를 연결할 수 있다.
5. 검색 결과가 현재 프로젝트 범위로 제한된다.
