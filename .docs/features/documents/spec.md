# 문서 기능 명세서

## 1. 목적

사용자가 프로젝트 내 마크다운 문서를 작성, 저장, 수정, 조회할 수 있어야 한다.

## 2. 주요 사용자 시나리오

- 사용자는 문서 생성 버튼으로 편집 화면에 진입한다.
- 좌측 영역에서 제목과 본문을 입력한다.
- 우측 영역에서 마크다운 미리보기를 즉시 확인한다.
- 저장 버튼을 눌러 문서를 저장한다.
- 기존 문서는 상세 또는 편집 화면에서 수정할 수 있다.

## 3. 입력 항목

- 제목: 필수
- 본문: 선택

## 4. 기능 요구사항

- 문서는 반드시 하나의 프로젝트에 속해야 한다.
- 문서 생성, 수정, 목록 조회, 상세 조회를 지원해야 한다.
- 편집 화면은 스플릿 뷰로 구성해야 한다.
- 좌측은 편집 영역, 우측은 프리뷰 영역이어야 한다.
- 프리뷰는 현재 입력 중인 본문 기준으로 즉시 갱신되어야 한다.
- 저장은 사용자의 명시적 액션으로만 수행해야 한다.

## 5. 검증 및 예외

- 제목은 공백만 입력할 수 없다.
- 본문은 비어 있어도 저장 가능해야 한다.
- 저장 실패 시 마지막 입력 상태를 유지해야 한다.
