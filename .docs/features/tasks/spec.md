# 태스크 기능 명세서

## 1. 목적

사용자가 프로젝트 내 태스크를 생성하고, 필요 시 특정 에픽에 소속시켜 관리할 수
있어야 한다.

## 2. 주요 사용자 시나리오

- 사용자는 프로젝트 또는 에픽 상세에서 태스크 생성 화면에 진입한다.
- 제목, 설명, 상태를 입력한다.
- 필요 시 소속 에픽을 선택한다.
- 생성된 태스크는 프로젝트 태스크 목록과 상세에서 조회된다.

## 3. 입력 항목

- 제목: 필수
- 설명: 선택
- 상태: 필수
- 소속 에픽: 선택

## 4. 기능 요구사항

- 태스크는 반드시 하나의 프로젝트에 속해야 한다.
- 태스크는 특정 에픽에 선택적으로 연결될 수 있어야 한다.
- 태스크 목록 및 상세 조회를 지원해야 한다.
- 태스크 상세에서는 연결된 문서 목록을 함께 확인할 수 있어야 한다.

## 5. 상태 규칙

- 허용 상태는 `backlog`, `todo`, `in progress`, `done` 네 가지다.
- 허용되지 않은 상태값은 저장할 수 없다.

## 6. 검증 및 예외

- 제목은 공백만 입력할 수 없다.
- 에픽을 선택하는 경우 현재 프로젝트 소속 에픽만 선택할 수 있어야 한다.
- 멤버가 아닌 사용자는 태스크 생성 및 조회를 할 수 없어야 한다.
