# 로그인 및 진입 정책서

## 1. 인증 정책

- 지원 인증 수단은 GitHub OAuth와 Google OAuth로 제한한다.
- 인증 제공자에서 받은 고유 식별자를 내부 사용자와 매핑해야 한다.
- 하나의 인증 성공은 하나의 내부 사용자 세션으로 귀결되어야 한다.

## 2. 프로필 정책

- 최초 로그인 시 프로필을 생성한다.
- 표시 이름, 이메일, 이미지 등은 제공 가능한 범위 내에서만 저장한다.
- 프로필 생성 실패 시 부분 로그인 상태를 허용하지 않는다.

## 3. 진입 정책

- 로그인 성공 후 기본 진입점은 프로젝트 목록이다.
- 사용자가 접근 가능한 프로젝트만 노출한다.
