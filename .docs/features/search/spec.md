# 검색 기능 명세서

## 1. 목적

사용자가 현재 프로젝트 내부에서만 에픽, 태스크, 문서를 검색할 수 있어야 한다.

## 2. 주요 사용자 시나리오

- 사용자는 프로젝트 컨텍스트 내 검색창에 키워드를 입력한다.
- 시스템은 현재 프로젝트 범위의 에픽, 태스크, 문서만 검색해 결과를 보여준다.
- 연결 추가 화면에서도 동일한 검색 범위 제한을 적용한다.

## 3. 검색 대상

- 에픽 제목, 설명
- 태스크 제목, 설명
- 문서 제목, 본문

## 4. 기능 요구사항

- 검색 범위는 현재 프로젝트 내부 데이터로 제한해야 한다.
- 다른 프로젝트의 에픽, 태스크, 문서는 검색 결과에 포함되면 안 된다.
- 연결 대상 검색도 동일한 범위 제한을 따라야 한다.
- 결과가 없으면 빈 상태를 보여줘야 한다.

## 5. 예외 처리

- 권한이 없는 프로젝트에서 발생한 검색 요청은 결과를 반환하지 않아야 한다.
- 검색 결과를 통해 다른 프로젝트 데이터 존재를 유추할 수 없어야 한다.
