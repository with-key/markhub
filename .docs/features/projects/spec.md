# 프로젝트 기능 명세서

## 1. 목적

사용자가 협업 단위인 프로젝트를 생성하고, 자신이 생성했거나 참여 중인 프로젝트를
목록으로 조회할 수 있어야 한다.

## 2. 주요 사용자 시나리오

- 사용자는 프로젝트 생성 버튼으로 2단계 생성 플로우에 진입한다.
- 1단계에서 프로젝트 이름과 설명을 입력한다.
- 2단계에서 초기 참여자 또는 운영 정보를 확인하고 생성 완료한다.
- 생성 완료 후 프로젝트 상세 또는 프로젝트 홈으로 이동한다.
- 사용자는 프로젝트 목록에서 본인이 접근 가능한 프로젝트를 확인한다.

## 3. 입력 항목

- 프로젝트 이름: 필수
- 프로젝트 설명: 선택
- 초기 참여자: 선택
- 운영 정보 확인: 선택 또는 기본값

## 4. 기능 요구사항

- 프로젝트 생성 플로우는 2단계로 구성해야 한다.
- 프로젝트 이름은 필수값이어야 한다.
- 생성 완료 시 생성자는 해당 프로젝트 멤버로 반드시 포함되어야 한다.
- 프로젝트 목록은 내가 생성한 프로젝트와 내가 속한 프로젝트를 함께 보여줘야 한다.
- 중복 참여 조건이 있더라도 동일 프로젝트는 목록에 한 번만 보여야 한다.

## 5. 검증 및 예외

- 프로젝트 이름은 공백만 입력할 수 없다.
- 필수값이 누락되면 다음 단계 이동 또는 생성 완료를 막아야 한다.
- 생성 실패 시 입력 중이던 값은 유지되어야 한다.
