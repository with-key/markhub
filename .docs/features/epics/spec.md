# 에픽 기능 명세서

## 1. 목적

사용자가 프로젝트 내 업무 묶음 단위인 에픽을 생성하고, 목록 및 상세를 조회할 수
있어야 한다.

## 2. 주요 사용자 시나리오

- 사용자는 프로젝트 내 에픽 생성 화면에 진입한다.
- 제목, 설명, 상태를 입력해 에픽을 생성한다.
- 생성된 에픽은 프로젝트 에픽 목록에 표시된다.
- 사용자는 에픽 상세 화면에서 기본 정보를 확인한다.

## 3. 입력 항목

- 제목: 필수
- 설명: 선택
- 상태: 필수

## 4. 기능 요구사항

- 에픽은 반드시 하나의 프로젝트에 속해야 한다.
- 에픽 생성 시 제목과 상태를 저장해야 한다.
- 프로젝트 단위 에픽 목록 조회를 지원해야 한다.
- 에픽 상세 조회를 지원해야 한다.

## 5. 검증 및 예외

- 제목은 공백만 입력할 수 없다.
- 상태는 시스템 허용값만 저장할 수 있어야 한다.
- 멤버가 아닌 사용자는 에픽 생성 및 조회를 할 수 없어야 한다.
