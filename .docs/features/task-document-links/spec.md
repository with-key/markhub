# 태스크-문서 연결 기능 명세서

## 1. 목적

사용자가 태스크와 관련 문서를 연결해 업무와 산출물 맥락을 함께 관리할 수 있어야
한다.

## 2. 주요 사용자 시나리오

- 사용자는 태스크 상세에서 관련 문서 추가 기능을 실행한다.
- 현재 프로젝트 문서 중 연결할 대상을 검색하거나 선택한다.
- 문서를 태스크에 연결한다.
- 연결된 문서는 태스크 상세에서 목록으로 조회된다.
- 사용자는 연결 해제를 수행할 수 있다.

## 3. 기능 요구사항

- 하나의 태스크에는 여러 문서를 연결할 수 있어야 한다.
- 하나의 문서는 여러 태스크에 연결될 수 있어야 한다.
- 연결 대상 검색은 현재 프로젝트 문서 범위로 제한해야 한다.
- 태스크 상세에서 연결된 문서 목록 조회를 지원해야 한다.
- 연결 해제를 지원해야 한다.

## 4. 검증 및 예외

- 연결 대상 문서는 현재 프로젝트 소속이어야 한다.
- 동일 태스크와 동일 문서의 중복 연결은 허용하지 않아야 한다.
- 멤버가 아닌 사용자는 연결 생성 및 해제를 할 수 없어야 한다.
